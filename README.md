# The poem about stopping

A short poem about agency: the power to stop and to stay. The program writes one text to `/output/entry.txt` — a hand resting on a kettle's handle, not turning it; nothing finished, nothing that has to be.

## Run

```sh
node main.ts
```

This writes `/output/entry.txt`.
